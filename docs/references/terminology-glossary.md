# 项目术语表（Glossary）

本项目统一术语口径的参考表。内容来源为 `src/utilities/changelog_text.opy` 的 `changelog_database`（玩家向 HUD 文案，长期由项目详细维护），据此总结项目内的玩法机制、效果、资源与英雄命名术语。

- 展示口径：changelog 文案仅 Team 2 玩家在重生室内可见（`src/modules/debug/changelog.opy`），本表术语以玩家向文案为准。
- 用途：统一项目内玩家向文案（changelog、平衡性说明）与开发讨论中的术语口径，供 `docs/workflows/ow-changelog-sync.md`、`docs/workflows/ow-balance-notes-writer.md` 引用。
- 维护：新增英雄机制、效果描述或数值口径时，先在此登记再进文案。

## 1. 项目与模式口径

| 术语 | 口径 |
| --- | --- |
| 常规赛 / main | `src/main.opy` 入口对应的玩法 |

| 玩家 / AI | 玩家（Team 2）与 AI（Team 1） |
| 重生室 | 出生点区域；部分效果限定重生室内 / 外生效 |

## 2. 数值面板（通用增减益）

## 4. 伤害结算与处决

| 术语 | 口径 | 文案示例 | 备注 |
| --- | --- | --- | --- |
| 最大生命值伤害 | 按目标最大生命值比例结算 | `每秒造成{1}%最大生命值伤害` | |
| 当前生命值伤害 | 按目标当前生命值比例结算 | `额外造成5%当前生命值伤害` | Junkrat |
| 已损失生命值 | 按缺失生命值比例结算 | `治疗目标全部已损失生命值`、`回复{2}%已损失生命值` | 治疗 / 回复通用 |
| 已造成伤害的生命值 | 按输出结算吸血 | `恢复100%已造成伤害的生命值` | |
| 额外伤害 | 追加伤害（固定值或比例） | `额外造成50点伤害` | |
| 真实伤害 | 直接削减目标生命值，不经过减伤链结算 | `造成{2}%最大生命值真实伤害`、`对护甲造成额外{7}%真实伤害` | `setHealth` 直接扣血；文案不再追加“无视减伤”等解释 |
| 处决 / 斩杀 | 生命值低于阈值时直接击杀 | `生命值低于20%则将其斩杀`、`直接处决` | 两词混用，建议统一为“处决” |
| 燃烧 | 持续灼烧（DOT） | `使敌方燃烧`、`使其燃烧{3}秒` | `BURNING`，可带“每秒X%最大生命值” |
| 印记 / 标记 | 命中后施加的增益结算标记 | `施加“狩猎”印记`、`施加3秒屠宰标记` | 带时长或层数 |
| 层数 | 可叠加计数，驱动后续收益 | `爆炸造成20 × 印记层数 额外伤害` | |
| 反弹 | 将受到伤害返还攻击者 | `反弹{1}%受到的伤害` | Orisa 强固防御 |
| 强化下一次攻击 | 周期性强化普攻 | `每3次攻击强化下一次攻击` | Sigma 超能之球 |
| 存储伤害 | 吸收并累计后附带 | `吸收伤害，最多存储{2}点` | Doomfist 悍猛格挡 |

## 6. 自定义机制与技能增强

- **自定义机制**：项目发明的专属状态 / 叠层 / 印记 / 低血被动 / 事件驱动链，改变玩法。
- **技能增强**：官方技能或英雄自身技能仅做数值 / 冷却 / 时长调整，无独立机制链。

### 6.3 文案与实现差异备注

- D.Mon 真实伤害（等离子剑 / 聚合发射器）：实现为 `setHealth` 直接削减目标生命值，不产生击杀归属 / 终极充能 / 伤害事件，也不先消耗 Armor / Shields / Overhealth（未复制原生生命层级扣除顺序）；`playerDealtDamage` 事件触发时目标必然存活且可被命中，无需额外防护判断。边界待实战验证。
- Domina 音速斥力场 / 爆能水晶：changelog 声称命中减速、击晕，当前代码仅实现冷却调整，减速 / 击晕未落地。
- Vendetta 沉默且不可阻挡：changelog 有此条，源码无对应实现（无 `SILENCED` 相关规则）。
- Vendetta 帕拉蒂尼之牙：changelog 与设置页均写"暴击"，实现未做暴击判定（普攻命中即触发），需核对。
- Wuyang 翻江浪：实现中冻结落点疑似为敌方 Wuyang 自身（`reset_pvar[14]`），与"命中同一目标2次后冻结"的描述相反，疑似 Bug，需核对。
- Anran 熠闪舞：实现含虚化 / 免控窗口，changelog 仅写冷却，未覆盖该效果。
- 官方技能名对照：Hazard 尖刺护体=Spike Guard、千针雨=Downpour；Sojourn 机体超频=Overclock、电磁炮=Railgun；Reaper 收割=The Reaping；Freja 瞄准射击=Take Aim（狩猎者为自造名）。官方英雄的标准技能名（如 生物手雷、维生力场 等）沿用游戏内官方中文名，不入上表。

> 新增自定义命名机制时必须在此登记；判定口径为"是否承载独立机制链"，而非"是否改了数值"。
