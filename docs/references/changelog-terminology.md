# Changelog 术语目录

- 来源：`src/utilities/changelog_text.opy` 的 `changelog_database`（玩家向 HUD 文案，main 与 aram 共用）。
- 展示约束：仅 Team 2 玩家在重生室内可见，见 `src/modules/debug/changelog.opy`。
- 用途：统一玩家向文案（changelog / 平衡性说明）中的术语口径，供 `docs/workflows/ow-changelog-sync.md` 与 `docs/workflows/ow-balance-notes-writer.md` 引用。
- 维护：新增英雄机制、效果描述或数值口径时，先在此登记再进文案。

## 1. 数值面板（通用增减益）

| 术语 | 口径 | 文案示例 | 备注 |
| --- | --- | --- | --- |
| 造成伤害 +X% / -X% | 玩家输出伤害面板修正 | `*造成伤害 +35%` | 正数为增强 |
| 受到伤害 +X% / -X% | 玩家承伤面板修正 | `*受到伤害 -30%` | 负数为增强 |
| 造成治疗 +X% | 治疗输出面板修正 | `*造成治疗 +22%` | |
| 暴击倍率提高至 ×X | 爆头 / 暴击倍率 | `暴击倍率提高至 ×3` | 用 `×` 而非 `x` |
| 暴击额外伤害 +X | 暴击时追加固定伤害 | `*暴击额外伤害 +{1}` | 与倍率是两种口径 |
| 弹道速度 +X% | 投射物飞行速度 | `*弹道速度+35%` | |
| 换弹速度 | 装填耗时（时间表述） | `换弹速度降低至0.75秒` | |
| 能量回复速度 +X% | 能量类资源回复速率 | `*能量回复速度 +25%` | Illari |
| 充能速度 +X% / 降低X% | 终极技能充能速率 | `*神射手 充能速度降低16%` | 与“终极充能”区分 |
| 移动速度 +X% | 移速修正 | `移动速度 +200%` | |
| 开镜伤害衰减 | 狙击开镜后的距离衰减 | `*移除开镜伤害衰减` | Widowmaker |
| 连射伤害提高X% | 副武器连射伤害 | `连射伤害提高{2}%` | Cassidy 维和者 |
| 减伤 / 伤害减免 | 非面板型的承伤减免 | `救生索 额外减伤35%`、`伤害减免提高至55%` | 与“受到伤害 -X%”区分 |
| 减疗 +X% | 目标受到治疗量降低 | `使敌方额外减疗{1}%` | Sombra 黑客入侵 |
| 持续时间 | 技能 / 形态时长（时间表述） | `持续时间提高至 15 秒` | |

## 3. 伤害结算与处决

| 术语 | 口径 | 文案示例 | 备注 |
| --- | --- | --- | --- |
| 最大生命值伤害 | 按目标最大生命值比例结算 | `每秒造成{1}%最大生命值伤害` | |
| 当前生命值伤害 | 按目标当前生命值比例结算 | `额外造成5%当前生命值伤害` | Junkrat |
| 已损失生命值 | 按缺失生命值比例结算 | `治疗目标全部已损失生命值`、`回复{2}%已损失生命值` | 治疗 / 回复通用 |
| 已造成伤害的生命值 | 按输出结算吸血 | `恢复100%已造成伤害的生命值` | |
| 额外伤害 | 追加伤害（固定值或比例） | `额外造成50点伤害` | |
| 处决 / 斩杀 | 生命值低于阈值时直接击杀 | `生命值低于20%则将其斩杀`、`直接处决` | 两词混用，建议统一为“处决” |
| 燃烧 | 持续灼烧（DOT） | `使敌方燃烧`、`使其燃烧{3}秒` | `BURNING`，可带“每秒X%最大生命值” |
| 印记 / 标记 | 命中后施加的增益结算标记 | `施加“狩猎”印记`、`施加3秒屠宰标记` | 带时长或层数 |
| 层数 | 可叠加计数，驱动后续收益 | `爆炸造成20 × 印记层数 额外伤害` | |
| 反弹 | 将受到伤害返还攻击者 | `反弹{1}%受到的伤害` | Orisa 强固防御 |
| 强化下一次攻击 | 周期性强化普攻 | `每3次攻击强化下一次攻击` | Sigma 超能之球 |
| 存储伤害 | 吸收并累计后附带 | `吸收伤害，最多存储{2}点` | Doomfist 悍猛格挡 |

## 6. 文案结构约定

| 记号 | 含义 | 示例 |
| --- | --- | --- |
| `●` | 英雄条目头行起始符 | `●{0}` |
| `*` | 一级条目（通用改动或技能条目） | `*造成伤害 +35%` |
| 技能名 + 换行 + 两空格缩进 | 技能条目下的子条目 | `*毒蛇` + 缩进子行 |
| `※※离开重生室隐藏` | 玩家离开重生室后隐藏该 HUD 文本 | 每条 changelog 末尾 |
| `约` | 非精确值（游戏内取整 / 显示误差） | `降低至约10.5秒` |
| `×` | 倍率乘号 | `暴击倍率提高至 ×3` |
| `点` | 固定数值单位 | `额外造成50点伤害` |
| `cd` / `CD` | 冷却时间缩写（建议统一为“冷却时间”全称，或与既有文案保持一致） | `返还0.5秒cd`、`击杀后重置CD` |
| `降低至` / `调整为` / `增加至` / `-X%` | 冷却时间数值改动措辞，须为时间表述 | `冷却时间降低至8秒` |
